# 🚀 Projeto Node.js — Sistema de Usuários

Projeto desenvolvido como parte da minha jornada de aprendizado em **Node.js**, com o objetivo de colocar em prática conceitos de desenvolvimento Back-End e integração com banco de dados.

> 📚 Este projeto representa uma etapa do meu aprendizado. Ainda há muito a aprender, mas cada projeto é uma oportunidade de evoluir na prática.

## 🎯 Objetivo

Desenvolver um pequeno sistema para trabalhar com **cadastro e gerenciamento de usuários**, utilizando Node.js e tecnologias relacionadas ao desenvolvimento Back-End.

O projeto também serviu como um exercício prático para testar meus conhecimentos e entender melhor a comunicação entre a aplicação e o banco de dados.

## ▶️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone SEU-LINK-DO-REPOSITORIO
```

### 2. Entre na pasta

```bash
cd conceito-node-2.0
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure as variáveis de ambiente

Crie um arquivo `.env` na raiz do projeto:

```env
DATABASE_URL="SUA_STRING_DE_CONEXAO"
```

Substitua pelo endereço de conexão do seu MongoDB Atlas.

### 5. Execute o projeto

```bash
npm run dev
```
